# `@deepseek-ai/dsh-supervisor-executor-inprocess`

[English](README.md) | 中文

本包是个人总控（Personal Supervisor）的第一个具体执行者适配器：向执行者桥注册，把路由后的任务变成项目工作区内的一次进程内一次性子运行。`prepare()` 只预占子会话身份，执行者桥因此能在任何模型工作开始前完成项目宿主租约准入；`start()` 用该预占 id 驱动共享的进程内驱动器，以路由给出的 provider/model 作为子会话路线，以项目真实路径作为子工作区。

子会话是真实的受派代理：全新上下文、盖章委派深度、应用委派范围声明与策略钉扎，一个终态结果映射到执行者桥的归一化词汇。取消、超时与处置顺序仍由桥持有。

## Model Experience

### 总控进程内执行者

#### 模型看到什么

主助理通过执行者桥收到紧凑的归一化运行结果。子会话看到路由提示与其自身的受派组合；适配器在持久一次性描述符之外不新增任何模型可见内容。

#### Token 影响

每次派发一个子运行。适配器不会把子会话转录复制进主控提示；完整输出保留在子会话中。

#### KV Cache 影响

稳定的执行者与 provider 名称让重复派发记录保持前缀稳定，直到路由策略变更。

## 已知边界与后续工单

- 路由 provider 白名单默认为空，因此适配器在所有者配置 bundle 行的 providers 之前保持休眠。
- 跨设备执行者（ACP、DSH SDK、外部 CLI）是未来的独立适配器包；本包只运行进程内子会话。
- 路由 provider 必须能被部署的 LLM 注册表解析，否则适配器启动即响亮失败。
