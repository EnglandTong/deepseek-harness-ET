# Agent Note：项目治理状态适配器

状态：proposed

[English](AGENT_NOTE.md) | 中文

## 问题

总控需要恢复当前项目事实，不能把所有项目文档或 Skill 正文复制进主对话。现有治理文件可能使用 `Docs` 或 `docs`，也可能不完整或互相冲突；冲突时猜测会让过期状态驱动派发。

## 方案

`ProjectStateAdapter` 执行有界且路径受限的读取，返回带来源路径、指纹、最近 Loop 记录和显式冲突状态的精简投影。默认只读；后续得到授权的组合层才可加入原子写入器。Skill handoff 只包含 Skill 名称、用途和按需加载提示。

## 验收标准

- Docs 查找大小写不敏感，并拒绝重复目录或指向目录外的 symlink。
- Packet、Work Order 和最近 Loop Runs 都是有界读取。
- 指纹使用规范化相对路径与原始字节，并能发现权威状态过期。
- 缺失、损坏、重复或越界来源都会产生冲突且零写入。
- 摘要不包含完整 Skill 正文、隐藏推理或完整历史。

## 风险

精简 Markdown 投影可能遗漏旧记录中的事实；显式冲突和来源引用允许治理消费者按需读取相关权威文件。Loop 记录是证据摘要，不是验收决定。
