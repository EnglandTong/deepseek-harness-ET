# Host Cost Controls 2.1.1

Apply only the adapter for the active host. Host commands and limits change; verify current host documentation before treating a value as fixed.

## Portable Rules

- Start a new session for an unrelated Work Order; resume the same goal from the Active Packet.
- Choose the model and reasoning profile before a long session where the host caches request prefixes.
- Attach a known file directly once when supported; do not attach duplicate copies later.
- Use quiet command flags and concise failure tails.
- Compact before a long pause when the host can reuse a warm cache, preserving goal, acceptance, scope, evidence, failure signature, and one next action.
- Roll back recent off-course turns when supported instead of preserving them in a summary.
- Isolate high-output work; keep small work local.

## Claude Code Adapter

- Use `/clear` between unrelated tasks and `/compact` within a continuing task.
- Prefer `@file` once per conversation for known files.
- Avoid unnecessary mid-session `/model`, `/effort`, or Fast mode changes.
- Use `/rewind` for recent unwanted turns when appropriate.
- Use a subagent for noisy logs or broad scans, not as overhead for a small fix.

Do not encode current prices, cache lifetime, output thresholds, model names, or version-specific commands in the portable contract.
