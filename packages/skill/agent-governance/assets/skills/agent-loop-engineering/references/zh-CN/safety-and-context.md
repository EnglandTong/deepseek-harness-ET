# 安全与上下文 2.1

## 真实路径写入边界

用 `realpath` 解析项目根目录、所有已存在目标，以及新目标最近的已存在父目录。相对真实路径越出项目根目录时拒绝操作，包括符号链接和 junction。

`write_scope: "."` 永远不授权项目外写入。读取已安装 Skill 说明或明确引用的公开资料不会扩大写权限。

## 硬停止

在密钥、账户 Session、生产/客户数据、付费资源、公开/生产变更、系统级安装、提权、破坏性或不可逆操作、受保护架构/数据/技术栈变化或权限外操作之前停止。

只有真正到达这些门禁时，才请求精确范围、影响、回滚和证据计划。

## 项目内自主权

项目规则未禁止时，Bounded Autopilot 可检查文件、修改授权源码/测试、安装项目声明依赖、创建一次性夹具、启动本地开发服务、运行项目检查，并修复当前范围导致或暴露的缺陷。

项目依赖安装不等于主机级安装。

## 上下文档位

| 档位 | 用途 | 软上限 |
| --- | --- | --- |
| Compact Small | 局部行为 | 6 文件 / 30k 字符 |
| Compact Medium | 子系统或重要流程 | 10 文件 / 60k 字符 |
| Compact Large | 已授权跨子系统工作 | 16 文件 / 100k 字符 |
| Audit | 全项目只读审计 | 每次单独预算 |

正常执行只读 Packet、当前动作、受影响源码/测试、验证配置和最近三条 Loop。fingerprint 未变时复用权威状态，不重复加载治理文件。

超过软上限时，说明所需证据，把当前事实压缩进 Packet，丢弃重复输出，再用更小工作集继续。预算耗尽不代表完成。

## 工具输出

- 可靠时使用 quiet reporter；
- 只有需要时把完整输出保存为一次性证据；
- 成功只返回精简摘要；
- 失败返回有用尾部，不返回数千条重复警告；
- 默认按 code 聚合校验发现，只有迁移审计才使用 `--strict-history`。

## 持久数据

禁止保存密钥、客户隐私、完整私有文档、对话、隐藏推理、完整命令日志或不必要的绝对机器路径。只保存证据引用、hash、精简可观察摘要和平台真实提供的可选使用量指标。
