# Host 成本控制 2.1.1

只应用当前 Host 的适配。Host 命令和限制会变化，把数值当成固定事实前先核对当前官方文档。

## 通用规则

- 无关 Work Order 使用新会话；同一目标从 Active Packet 恢复。
- Host 使用请求前缀缓存时，在长会话开始前选择模型和推理档位。
- 支持时，对已知文件直接附加一次，后续不要重复附加副本。
- 命令使用 quiet 参数，失败只保留有效尾部。
- Host 可复用热缓存时，在长时间暂停前压缩，并保留目标、验收、范围、证据、失败签名和唯一下一步。
- 支持回退时，删除近期跑偏轮次，不把错误路线保存进摘要。
- 隔离高输出工作，小型工作留在主上下文。

## Claude Code 适配

- 无关任务之间使用 `/clear`，同一任务内使用 `/compact`。
- 已知文件每个会话只使用一次 `@file`。
- 避免不必要的会话中途 `/model`、`/effort` 或 Fast mode 切换。
- 近期轮次跑偏时，适当使用 `/rewind`。
- 嘈杂日志或大范围扫描使用子 Agent，小修复不要增加委派开销。

不要把当前价格、缓存时间、输出阈值、模型名称或版本特定命令写进通用契约。
